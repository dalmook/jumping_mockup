# 점핑배틀 화성병점점 예약 UX 목업 3종

현재 고객 예약 화면의 정보만 활용한 클릭형 정적 HTML 목업입니다.

- **1순위 김캐디형**: 방별 예약 가능 상태와 권장 인원을 먼저 보여주는 구조
- **2순위 캐치테이블형**: `지금 이용하기`와 `시간 예약하기`를 먼저 나누는 구조
- **3순위 토스형**: 한 화면에 질문 하나만 보여주는 단계형 구조

## 실행

별도 설치 없이 `index.html`을 열면 됩니다.

로컬 서버로 확인하려면:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## GitHub Pages

이 저장소에는 GitHub Pages 배포용 Actions 워크플로가 포함되어 있습니다.

1. GitHub 저장소의 **Settings → Pages**로 이동
2. Source를 **GitHub Actions**로 선택
3. `main` 브랜치에 push하면 자동 배포

## 참고한 기존 예약 정보

- 총 16분 이용: 설명 1분 + 실제 게임 15분
- 예약 간격 20분
- 성인 7,000원 / 청소년·어린이 5,000원
- 방: 소형 C2, 대형 B1, 소형 C1, 중형 A1
- 권장 인원: C2 2~4명, B1 4~8명, C1 2~4명, A1 2~6명
- 난이도: 키즈, 베이직, 여름, 이지, 우주, 노멀, 산타, 점핑 하드, 챌린저
- 입력 정보: 날짜, 시간, 방, 인원, 팀명, 난이도, 차량번호 뒤 4자리, 안전 동의

## 주의

이 프로젝트는 UI 비교용 목업입니다. 실제 예약 API, 결제, 고객 데이터 저장 기능은 포함하지 않습니다.
